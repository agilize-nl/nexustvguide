# Nexus TV Gids — logo-concepten

Drie visuele richtingen voor de nieuwe app-identiteit:

1. `concept-1-nexus-beam.png` — Nexus-monogram met play-beweging.
2. `concept-2-live-grid.png` — EPG-programmablokken met een live-lijn.
3. `concept-3-focus-play.png` — D-pad/focuskader rond playback.

De concepten zijn AI-gegenereerde rastervoorstellen. **Concept 1, Nexus Beam, is
geselecteerd.** Het is opnieuw opgebouwd als deterministische productie-asset voor de
legacy launcher, adaptive icon en TV-banner; zie `android/app/src/main/res/`. De
geometry-first generator staat in `tools/generate-nexus-beam-assets.mjs`.
